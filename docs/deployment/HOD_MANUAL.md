# Head of Department User Manual — v1.0

1. Sign in using the HoD account. Select a course within your department and choose an assignment.
2. Review the marked submissions, their final marks, penalties and feedback.
3. Select a marked submission and click **Approve selected**; alternatively select **Approve all marked** when appropriate.
4. To correct an eligible marked result before approval, choose **Change mark...** and enter a reason. The system records the change in its audit history.
5. Select **History...** to inspect the recorded marking changes.
6. Click **Release marks...** to release moderated submissions. Only approved (moderated) marks are released; students will then see their marks and feedback and receive notices.
7. Check the displayed statuses, use **Refresh** when needed, then **Log out**.

Do not release unreviewed work. A released mark is final in the current implementation, so complete corrections before approval/release.
