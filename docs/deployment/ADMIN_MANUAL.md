# Administrator User Manual — v1.0

1. Open the LMS and sign in with your administrator username and password.
2. Use **Users** to view users and statuses. Click **New user...** to create an account; select a user to **Deactivate**, **Reactivate**, or **Reset password...**.
3. Use **Courses** to review existing courses and their assigned lecturers and student counts.
4. Click **New department...** to create a department, or **New course...** to enter its code, title and department.
5. Select a course and click **Assign lecturer...** to choose its lecturer; click **Enrol student...** to add a student.
6. Use **Audit log** to inspect recorded marking changes. Use **Refresh** when another action has changed the displayed data.
7. Click **Log out** when finished.

Do not use shared demonstration passwords in a real school. Only manage learner data for authorised purposes. If a database error appears, record the message and refer it to the technician instead of retrying repeatedly.
